# W44 测试清单（2026-10-26 ~ 11-01）

这周工具和 Excel 并行跑一遍，对一下结果。PSI 里最后还是按你自己 Excel 的结果来填，工具这周只做对照。

## 第 1 步：下载到一个文件夹，让工具整理

把这周收到的周报（xlsx / xls / .msg 邮件 / zip 都行）全部下载到**同一个文件夹**，不用改名、不用分类，比如 `~/Downloads/PSI_W44`。然后运行：

```
.venv/bin/python -m tools.sort_downloads ~/Downloads/PSI_W44 --week 44 --dest "W44测试/W44原始文件"
```

工具会按文件内容认出每个文件是哪一家、哪一周，放进下面对应的文件夹，并写一份 `W44原始文件/整理记录.md`：
- 邮件里的附件、zip 里的文件会被取出来分别归类；
- 不是 W44 的文件放到 `W44测试/_其他周/`，不会混进来；
- 同名但内容不同的文件（比如一份邮件原件、一份你改过的副本）放到 `W44测试/_同名不同内容/`，工具只读原件；
- 认不出来的文件留在下载文件夹里，记录里会列出来。

想先看看会怎么放、不动文件，就加 `--dry-run`；想保留下载文件夹原样，就加 `--copy`。

## 第 2 步：跑工具

在 PSI_agent 文件夹里运行：

```
.venv/bin/python -m psi_tool.run --week 44 --inbox "W44测试/W44原始文件" --out "W44测试/工具结果"
```

结果有两个：
- `工具结果/W44_report.md`：哪家收到了、哪家没收到，未匹配的型号，各种提示；
- `工具结果/W44_paste.xlsx`：每张 PSI sheet 一页，可以直接粘贴的数。

收到一部分就可以先跑，后面收到新文件再跑一次会覆盖结果。

## 第 3 步：Excel 照常做

- OM：照原来的方法做，按 TTL ID 表匹配。**Auchan 的库存改了：Zapas Bieżący + Zapas Magazynowy 两列相加**（工具已按这个算）。
- 运营商：用 `mapping/PSI码对照表.xlsx` 匹配，"说明"页里有公式（TMO 会自动去掉 DEMO / SAMPLE / Outlet / reSTART，以及名称以大写 CR 结尾的特殊版本；小写 bi 是白色，要计入）。
- DB：AB 透视表的值字段记得用**求和**。
- **不要沿用上周文件的 CODE**，上周写错的会一起带过来。直接按 `mapping/PSI码对照表.xlsx` 匹配，方法见 `docs/对照表核对方法.md`。匹配完按代码筛选，看名称和代码是否一致；`15C 5G B2B`（XA-H-T117040）归 P154+128，不是 O19。
- 改完 CODE 或透视表的数据源后要刷新透视表，再粘贴进 PSI。
- PSI 的筛选视图可能只显示 ST 行，SO 和库存行被隐藏。填数时确认平板（TAB）也显示出来，比如 Orange 的 P836+128、P828+256。

## 第 4 步：对数（脚本自动比）

1. 生成手工结果模板（第 2 步工具跑完之后）：

```
.venv/bin/python -m tools.compare_manual --week 44 --template
```

2. 打开 `Excel手工/W44_手工结果.xlsx`：
   - 每张 PSI sheet 一页，代码已经按 PSI 筛选后的顺序排好，和你往 PSI 里粘贴的顺序一样；
   - 把你 SUMIF / 透视表的结果粘贴进绿色的"你的 SO""你的库存"两列；
   - 运营商只填有数的代码也行，空着的格子不比；
   - "DB 合计"页填 AB / ALSO / IM 的 ST 合计和库存合计。
3. 对数：

```
.venv/bin/python -m tools.compare_manual --week 44
```

结果在 `Excel手工/W44_对数结果.md`（总结）和 `W44_对数结果.xlsx`（不一样的格子逐条列出，标红）。
对不上的地方，先看工具报告里这一家有没有提示（未匹配、冲正、排除的样机等）；查不出来就把那一节发给我。

## 第 5 步：PSI 填完后的复核（可选）

从飞书重新导出 PSI，覆盖 `数据/Poland PSI DB+Channel.xlsx`，再加 `--compare` 跑一次：

```
.venv/bin/python -m psi_tool.run --week 44 --inbox "W44测试/W44原始文件" --out "W44测试/工具结果" --compare
```

报告会逐格列出 PSI 里填的数和工具结果不一样的地方。
