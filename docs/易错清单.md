# PSI 周报易错清单

来自 W44（2026-10-26 ~ 11-01）四家运营商的工具和手工对账。每周填 PSI 前过一遍。

## 一、填数时最容易犯的错

| # | 错误 | W44 的例子 | 为什么会错 | 下次怎么防 |
|---|---|---|---|---|
| 1 | 沿用上周的 CODE，把错误一起带过来 | TMO `15C 5G B2B`（XA-H-T117040）写成 O19，O198+256 库存多算 | CODE 是查上周文件得来的，上周错了这周也错 | 按 `PSI码对照表.xlsx` 匹配，不查上周文件 |
| 2 | 名字只差一点，看成同一个产品 | Note 12 写成 Redmi 12（M19E）；15C 5G 写成 15 5G | Redmi 12 / Note 12 / 12 5G、15 / 15C / 15 5G 都是不同产品 | 匹配完按代码筛选，逐行看名称 |
| 3 | 透视表没刷新 | TMO 透视表的 SO 比 CODE 列少 | 改了 CODE 没有刷新 | 粘贴前刷新；合计和 CODE 列再对一次 |
| 4 | PSI 粘贴错行 | Play P7E8+256 填成了和 O7E8+256 一样的数 | 手工逐格填，行容易错位 | 填完跑 `--compare` |
| 5 | 筛选把行藏起来，整个品类漏填 | Orange P836+128、P828+256 从 W42 起没填 | PSI 筛选视图只显示 ST 行，平板容易被漏掉 | 填前确认 SO、库存行和 TAB 品类都显示了 |
| 6 | 新颜色或新物料查不到 | TMO `Note 13 Pro+ ... bi` 是 #N/A，SO 少算 | 上周文件里没有这个物料 | CODE 是 #N/A 的行都要看一遍，有 SO 或库存的不能跳过 |
| 7 | 别人的表标错规格 | Jet 表写 `Redmi 15 5G 4/128`，原始文件是 8/256 | 只看了转手的汇总表 | 规格和库存以运营商原始文件为准，矛盾时问负责人 |
| 8 | 两份口径不同的报表对不上，以为是填错 | IM：Mobility 7 台 / IMEI List 40 台（MEDIA SATURN，Pad 2 Pro 8+256） | IMEI List 按发货日期、Mobility 按发票日期算周，账期口径不同 | IM 一律以 Mobility 为准；IMEI 只作参考，差额不用处理 |
| 9 | 客户名里多了空格，公式查不到客户 | IM 的 `Euro-net Sp.  z o.o.`（两个空格），W45 有 8,830 台差点漏算 | 工具表2 按单空格查 | 贴之前去掉多余空格（工具已自动处理） |

## 二、尾缀怎么判断

| 尾缀 | 是什么 | 怎么处理 |
|---|---|---|
| `bi`、`cz`、`fi`、`ni`、`nie`、`sz`、`Bia`、`Cza` | 颜色被截断（biały、czarny 等） | **不用管，不排除**。负责人已确认；想知道颜色看 TTL 的 Color 列 |
| `DEMO`、`SAMPLE`、`Outlet`、`reSTART`（可能截断成 `reSTAR`、`Outl`） | 样机、翻新机 | 不计入 |
| 大写 `CR` | 特殊版本 | 不计入 |
| `B2B` | 正常销售渠道的货 | **计入**，按型号归类，例如 `15C 5G B2B` 归 P154+128 |
| Orange 开头的 `E.` | 门店展示机 | 不计入 |
| Play `UZZ` | 含义待确认 | **不计入**（胡佳琪确认），工具按名称排除 |
| TMO `COAR` | 含义待确认 | **待办**，暂时保持原来的处理，没有写成规则 |

## 五、对照表为什么会出错

1. **沿用历史写法：** 手工表查上周文件，工具的 `learned` 映射也来自历史周报，历史错了就一直错。
2. **只按项目名和内存自动匹配：** 工具早期的 `auto` 映射忽略了 5G、品牌和套装。比如 Plus 的 `13 5G` 没写品牌，被匹配成 Redmi 13。
3. **PSI 和 TTL 自身也有错：** 见下面第六部分。所以任何一个来源都不能单独作为依据。

## 六、源表自身的问题（建议找表的负责人修）

完整列表在 `mapping/PSI码对照表.xlsx` 的“TTL表的问题”“PSI名称的问题”两页。

| 表 | 问题 | 影响 |
|---|---|---|
| TTL | 有 1 个 EAN 同时对应 O178+256 和 P12U12+256（详见本地对照表） | OM 按 EAN 匹配时可能串 |
| TTL | 3 个 `Redmi 15C 5G Mint Green 4/256` 的 EAN 被标成 POCO M7 Pro 5G（O17P12+512） | 同上 |
| TTL | `Redmi Pad 2 Pro 8/256` 的内存列写 6+128，代码是 P838+256 | 按内存列查会错 |
| TTL | `Xiaomi 15 Ultra` 一行内存列写 6+512，另一行 CODE 列写 O11 | 同上 |
| TTL | 新品的 Short Name、内存列常常是空的，或只有开发代号（LEEDSA-EU） | 按名称查不到 |
| PSI | O19 在部分表叫 `Redmi 14 5G`，其他表叫 `Redmi 15 5G`；O19AE 同样 | 按名称匹配容易错。O19 是 Redmi 15 系列 |
| PSI | O84XE 在部分表叫 `Redmi Pad ? 4G` | 同上 |
